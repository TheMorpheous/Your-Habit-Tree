# Your-Habit-Tree
To track your daily habits and goals, designed to assist those who struggle with keeping themselves accountable.

How to Run Program 
1. Clone Repository and Run
2. Ensure You have
3. 3.x Python
4. Code Editor Such as VS Code (What I Used)

Features 
- Login and Create Acc
- Save Acc Progress
- Track Acc Daily Progress in Habits
- Tree Grows when You have Completed a Habit
- Tree Shrinks when Habit is Missed
- Cant do Multiple Habit Logs on Same Day
- Tracks Acc Longest Streak
- Tracks Acc Current Streak
- Tracks Total Days Completed
- 30 Day Habit History (Missed / Completed)
- Automatically Saves Your Acc's Progress
